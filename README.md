Pathfinder BD is a C-based public bus route finder designed to help passengers find possible routes between locations, compare travel costs, and choose a suitable journey.

- Find available bus routes.
- Find the cheapest route using Dijkstra's Algorithm.
- Find routes with the fewest bus segments using BFS.
- Calculate estimated journey fares.
- Display bus stops and bus changes.
- Search available starting points and destinations.
- C Programming Language
- Data Structures and Algorithms (DSA)
- Graphs
- Dijkstra's Algorithm
- Breadth-First Search (BFS)

1. Clone the repository

git clone https://github.com/sayeem2006/Pathfinder-BD.git

2. Open the project folder

cd Pathfinder-BD

3. Compile the program

Using GCC:

gcc -std=c99 -Wall -Wextra -pedantic main.c -o pathfinder

4. Run the program

Windows:

pathfinder.exe

Linux / macOS:

./pathfinder

Alternatively, if GNU Make is installed:

make
make run

This project currently uses sample bus routes and fares for demonstration purposes. They are not verified real-world transport information.
